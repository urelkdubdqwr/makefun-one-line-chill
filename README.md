One line of horror, a single sentence under 200 characters that frightens in one breath. main.py writes it to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```

## About the line

This entry trades jump scares for dread, leaning on a mundane detail that turns sinister on a second read. It aims to feel ordinary at first, then quietly wrong, letting the reader do the work of realizing what changed. The goal is a single breath of unease that lingers well after the sentence ends.
